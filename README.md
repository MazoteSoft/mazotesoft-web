# MazoteSoft - Official Website

> **High-Performance Mobile Apps & Games Studio**

## 🌟 Overview

This repository contains the source code for the official website of **MazoteSoft**. Designed with a modern aesthetic featuring professional blue and white palettes, glassmorphism, dynamic micro-animations, and full mobile responsiveness.

### Key Sections:
- **Hero & Interactive Device Demo:** Showcases real-time 60 FPS mobile simulation and core capabilities.
- **Metrics Strip:** Animated stat counters highlighting engineering standards and crash-free stability.
- **About Us:** Studio mission, player-first philosophy, and agile sprint approach.
- **Services:** Full-cycle mobile game development (Unity/3D), custom mobile apps (iOS & Android), UI/UX design, cloud backends, ad monetization, and store publishing.
- **Featured Portfolio:** Showcase spotlighting titles such as *RogueDraft* and *LottoCol* with interactive category filtering.
- **Tech Stack:** Highlighting Unity, Flutter, Swift, Kotlin, Firebase, and Figma.
- **Contact & Inquiry Form:** Form with validation, direct contact channels, and email integration.
- **Floating WhatsApp Widget:** Direct instant communication via WhatsApp with a prefilled message.

## 🚀 Live Preview / Local Setup

No complicated build steps or heavy dependencies required. The site is built with clean, modern HTML5, CSS3, and Vanilla JavaScript.

1. Clone or navigate to the repository:
   ```bash
   cd C:\Proyectos\mazotesoft-web
   ```

2. Open `index.html` in any modern web browser, or serve it using Python's built-in HTTP server:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` in your browser.

## 🎨 Design System

## 📱 WhatsApp Integration

The floating WhatsApp button at the bottom-right links directly to WhatsApp with a preconfigured message. To customize the phone number or greeting, update the `href` attribute in `index.html`:
```html
https://wa.me/<YOUR_PHONE_NUMBER>?text=Hello%20MazoteSoft!%20...
```
